Featured — ft_transcendence Capstone 9 Services

ASSAS SIEM

A production-grade Security Information and Event Management platform, built from scratch as the 42 capstone project. Covers the entire SOC analyst workflow — from raw endpoint telemetry ingestion to alert triage, incident resolution, threat intelligence correlation, and real-time team coordination. Nine containerized services orchestrated via Docker Compose.

React Nest.js TypeScript PostgreSQL Redis Socket.io BullMQ Docker Compose C++ Agent
01

Auth & Core Infrastructure

Admin-provisioned user accounts (no self-registration). Role-based access control with granular permissions stored as JSON. Team management with leaders and members. Immutable audit trail logging. WAF middleware blocking XSS, SQL injection, and path traversal. Redis-backed rate limiting. Full Docker Compose orchestration for all 9 services.

JWT RBAC WAF Audit Logs Teams Rate Limiting
02

Event Stream & Device Management

Endpoint agent registration with pre-shared token authentication (DeviceAuthGuard). High-throughput event ingestion API with category typing and source IP tracking. Real-time event broadcast to all connected analysts via WebSocket (Socket.io). Heartbeat monitoring with configurable intervals. Automatic offline detection and alert generation when agents go silent.

WebSocket Agent Auth Heartbeat Event Ingestion Real-time Broadcast
03

Alert Engine & Incident Management

5-stage alert lifecycle (New, Acknowledged, Investigating, Resolved, Closed) with severity levels and analyst assignment. CRUD correlation rules engine that evaluates incoming events against configurable patterns. Alert-to-ticket conversion. 6-stage incident ticket workflow (Backlog through Closed) with a full Kanban board UI, comments, history, and SLA tracking. Automatic war room (ChatRoom) creation per alert and ticket.

State Machine Kanban Board Correlation Rules SLA Tracking War Rooms
04

Threat Intelligence & Chat

Indicator of Compromise database with typed entries, threat scores, and expiration tracking. Automated feed ingestion from MISP, AlienVault OTX, and STIX/TAXII sources via BullMQ background jobs. Enrichment lookups that match incoming events to known IoCs and auto-escalate severity. Real-time team chat and per-incident war rooms via Socket.io WebSocket with typing indicators and full message history search.

MISP STIX/TAXII BullMQ Jobs Real-time Chat IoC Matching Enrichment
05

Dashboards, Reports & C++ Agent

Widget-based custom dashboards with 9 widget types (event counter, alert list, severity chart, timeline, device status, incident board, threat map, activity feed, system health). Drag-and-drop layout with auto-refresh and team-level sharing. Scheduled PDF/CSV report generation linked to alerts and files. A custom C++ endpoint agent that collects system metrics, tails log files, sends heartbeats, and reports events back to the SIEM over the network.

9 Widget Types Drag & Drop PDF/CSV Export C++ Agent Prometheus
